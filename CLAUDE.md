# Repository instructions

Read PROJECT_WORKFLOW.md at the repository root before starting work. Treat it as the shared workflow for this repository.

For an existing project, read its PROGRESS.md, README.md and relevant source files. If these files are unavailable, request them. Do not rely on assumed conversation memory.

Use simple Bangla explanations. Start a new project with its full breakdown, then guide one verified step at a time. Update progress with evidence and the exact next action. Never invent a successful test or GitHub push.

Maintain shared rules in PROJECT_WORKFLOW.md rather than duplicating them here.
