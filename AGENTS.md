# Repository instructions

Before working, read PROJECT_WORKFLOW.md at the repository root. It is the shared workflow for this repository.

For an existing project, also read its PROGRESS.md, README.md and relevant source files. Follow applicable project-specific instructions. If files are inaccessible, say so and request them instead of pretending to have read them.

Explain in simple Bangla, give the full breakdown for a new project, then proceed one verified step at a time. Record verified progress and an exact next action. Do not invent test results, deployment status or previous completion.

Keep shared rules in PROJECT_WORKFLOW.md rather than duplicating them here.
